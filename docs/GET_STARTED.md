# M3TAL Getting Started Guide

This guide provides a step-by-step process for setting up M3TAL on your system for the first time.

---

## Step 1: Prerequisites

Docker Engine and Docker Compose V2 must be installed on your system.
Verify their installation by running:

```bash
docker --version && docker compose version
```

Expected output (versions may vary):

```
Docker version 24.0.5, build a61e2b4
Docker Compose version v2.20.2
```

---

## Step 2: Install M3TAL via APT

Use the following commands to install the M3TAL CLI and API daemon:

```bash
# 1. Add the GPG signing key
curl -fsSL https://jakej985-rgb.github.io/m3tal-core/KEY.gpg | sudo gpg --dearmor -o /usr/share/keyrings/m3tal-archive-keyring.gpg

# 2. Add the APT repository
echo "deb [signed-by=/usr/share/keyrings/m3tal-archive-keyring.gpg] https://jakej985-rgb.github.io/m3tal-core stable main" | sudo tee /etc/apt/sources.list.d/m3tal.list

# 3. Install
sudo apt update && sudo apt install -y m3tal
```

---

## Step 3: Run the Configuration Wizard

After installation, run the M3TAL configuration wizard to set up essential environment variables:

```bash
sudo m3tal config wizard
```

The wizard will prompt you for several configurations. Here's an explanation of key prompts:

*   **`DASHBOARD_EXPOSE_MODE`**:
    *   **`local` (default)**: The M3TAL Dashboard will be directly accessible via `http://YOUR_IP:8082`. This is suitable for most first-time users and LAN-only setups. No Traefik configuration is needed for dashboard access.
    *   **`traefik`**: The M3TAL Dashboard will be routed through the Traefik reverse proxy, accessible via `http://dash.YOUR_DOMAIN`. This requires Traefik to be running and a configured `DOMAIN`.
*   **`DOMAIN`**: The base domain for services exposed via Traefik (e.g., `example.com`). If you select `traefik` mode for the dashboard, it will be accessible at `dash.DOMAIN`. For `local` mode, this can be `localhost`.
*   **`PUID` (User ID)** and **`PGID` (Group ID)**: These are the User ID and Group ID that Docker containers will use to access host filesystem resources. This is crucial for file permissions. You can find your current user's IDs with `id -u` and `id -g`.
*   **`DASHBOARD_PORT`**: The port on which the M3TAL Dashboard will be exposed if `DASHBOARD_EXPOSE_MODE` is `local`. Default is `8082`.
*   **`TZ` (Time Zone)**: Set your system's timezone (e.g., `America/New_York`).
*   **`DASHBOARD_SECRET`**: A secret key used by the dashboard for security. A random one is generated by default; it's recommended to accept this.
*   **`ADMIN_PASSWORD`**: The default password for the `admin` user on the M3TAL Dashboard. You will change this after logging in.

---

## Step 4: Start the Routing Stack (Traefik)

The `m3tal up` command starts all Docker Compose stacks found in the `/docker/` directory. This typically includes the `routing-compose.yml` which deploys Traefik, the reverse proxy for your services.

```bash
m3tal up
```

This command will:
*   Download necessary Docker images (e.g., `traefik:latest`).
*   Start the Traefik container. Traefik will listen on port 80 and automatically discover services with Docker labels, providing domain-based routing.

---

## Step 5: Start the M3TAL Dashboard

The `m3tal dash up` command specifically manages the M3TAL Dashboard container:

```bash
m3tal dash up
```

This command performs the following actions:
1.  Downloads the latest dashboard-related Docker Compose files (`m3tal-compose.yml`, `m3tal-compose.local.yml`, `m3tal-compose.traefik.yml`).
2.  Reads the `DASHBOARD_EXPOSE_MODE` variable from `/etc/m3tal/.env`.
3.  Starts the `m3tal-dashboard` container using the appropriate Compose override file (`m3tal-compose.local.yml` for `local` mode or `m3tal-compose.traefik.yml` for `traefik` mode). This ensures the dashboard is accessible according to your chosen mode.

---

## Step 6: Open the M3TAL Dashboard in Your Browser

Access the M3TAL Dashboard based on your `DASHBOARD_EXPOSE_MODE` setting:

*   **If `DASHBOARD_EXPOSE_MODE` is `local` (default):**
    Open your web browser and navigate to `http://YOUR_IP:8082` (replace `YOUR_IP` with the actual IP address of your server). If accessing from the same machine, you can use `http://localhost:8082`.

*   **If `DASHBOARD_EXPOSE_MODE` is `traefik`:**
    Open your web browser and navigate to `http://dash.YOUR_DOMAIN` (replace `YOUR_DOMAIN` with the domain you configured in Step 3). Traefik must be running for this to work.

---

## Step 7: Log In to the Dashboard

The default login credentials are:

*   **Username**: `admin`
*   **Password**: `admin_pass` (or the password you set during the wizard)

**Immediately change the default password after your first login.**
You can change the dashboard administrator password using the M3TAL CLI:

```bash
sudo m3tal dashpass
```

This command will prompt you to enter a new password for the `admin` user.

## Filesystem Contract

M3TAL establishes a clear filesystem contract for its operations:

| Path                        | Purpose                                                                                |
| :-------------------------- | :------------------------------------------------------------------------------------- |
| `/etc/m3tal/.env`           | Primary configuration file for M3TAL. Managed by `m3tal config wizard` and `m3tal config set`. |
| `/var/lib/m3tal/state.db`   | SQLite state database storing M3TAL's internal state. Auto-created by the API daemon.  |
| `/opt/m3tal/stack/`         | Canonical directory where M3TAL stores its core Docker Compose files (e.g., `routing-compose.yml`). |
| `/docker`                   | A symbolic link to `/opt/m3tal/stack/`. This is the user-facing path for placing your custom Docker Compose stacks and configuration. |
| `/docker/users.json`        | Dashboard credential store. Managed by `m3tal dashpass`.                               |

---

## Port Table

M3TAL uses the following ports for its core components:

| Port | Service               | Access Level                                |
| :--- | :-------------------- | :------------------------------------------ |
| `80` | Traefik HTTP entry point | Public (if `TRAEFIK_WEB_PORT` is 80)        |
| `8080` | M3TAL API daemon (Go) | Host-local (accessible by containers via `host.docker.internal:8080`) |
| `8081` | Traefik dashboard     | Host-local only (e.g., `http://localhost:8081`) |
| `8082` | M3TAL Dashboard       | Direct port (if `DASHBOARD_EXPOSE_MODE=local`) or via Traefik (if `DASHBOARD_EXPOSE_MODE=traefik`) |

---

## Firewall Note

If your server has a firewall (e.g., UFW) enabled, you may need to open ports to allow external access to your services.

*   **For Traefik (if exposed on port 80):**
    ```bash
    sudo ufw allow 80/tcp
    ```
*   **For M3TAL Dashboard (if `DASHBOARD_EXPOSE_MODE=local`):**
    ```bash
    sudo ufw allow 8082/tcp
    ```
    After allowing ports, enable/reload UFW:
    ```bash
    sudo ufw enable
    # Or if already enabled
    sudo ufw reload
    ```

## Service Management

The M3TAL API daemon runs as a systemd service named `m3tal-api.service`. You can manage it using standard `systemctl` commands:

*   **Check the status of the M3TAL API daemon:**
    ```bash
    systemctl status m3tal-api
    ```
*   **View real-time logs for the M3TAL API daemon:**
    ```bash
    journalctl -u m3tal-api -f
    ```
*   **Restart the M3TAL API daemon:**
    ```bash
    sudo systemctl restart m3tal-api
    ```

## What's Next? (Day 2 Operations)

M3TAL uses Docker Engine and Docker Compose V2 to manage your services.
*   The `m3tal up` command operates on all `*-compose.yml` files present in the `/docker/` symlinked directory. This includes the `routing-compose.yml` (Traefik, Cloudflared) and any additional stacks you add.
*   The `m3tal dash up` command is specifically for managing the M3TAL Dashboard container, ensuring it uses the correct exposure mode.

To deploy new applications or services with M3TAL:
1.  Create your Docker Compose file (e.g., `my-app-compose.yml`).
2.  Place this file into the `/docker/` directory.
3.  Ensure any required environment variables for your stack are set in `/etc/m3tal/.env` (use `m3tal config wizard` or `m3tal config set KEY value`).
4.  Run `m3tal up` to deploy your new stack alongside existing ones.
