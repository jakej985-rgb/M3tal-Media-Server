# M3TAL Ecosystem: Command Reference

> **DocSmith Note:** This guide serves as the official operational manual for the `m3tal` CLI. Ensure you have the binary in your PATH and proper permissions to interact with the Docker daemon and local state paths.

---

## 1. Global Orchestration
The `m3tal` binary is the primary control plane for the ecosystem.

| Command | Description | Example |
| :--- | :--- | :--- |
| `m3tal` | Launches the interactive TUI Control Center. | `m3tal` |
| `m3tal init` | Generates default `.env` at `/etc/m3tal/.env`. | `m3tal init` |
| `m3tal doctor` | Executes pre-flight hardware and service health checks. | `m3tal doctor` |

---

## 2. Authentication & Security
Manage system credentials and access tokens.

| Command | Description | Example |
| :--- | :--- | :--- |
| `m3tal dashpass` | Sets Dashboard credentials. | `m3tal dashpass admin secret123` |
| *No Args* | Triggers interactive prompt. | `m3tal dashpass` |

---

## 3. Configuration Management (`m3tal config`)
Handles environment variables and system state settings.

| Subcommand | Description | Example |
| :--- | :--- | :--- |
| `wizard` | Opens guided terminal setup for variables. | `m3tal config wizard` |
| `set` | Sets a specific environment variable. | `m3tal config set LOG_LEVEL debug` |
| `get` | Retrieves value for a specific key. | `m3tal config get DASHBOARD_PORT` |
| `scan` | Re-syncs environment variables from file to binary. | `m3tal config scan` |
| `list` | Lists all configured environment variables. | `m3tal config list` |

---

## 4. Service & Dashboard Control
Controls the state of the management container layer.

| Command | Description | Example |
| :--- | :--- | :--- |
| `m3tal dash up` | Deploys the Dashboard container. | `m3tal dash up` |
| `m3tal dash down` | Removes the Dashboard container. | `m3tal dash down` |
| `m3tal dash restart` | Restarts the Dashboard service. | `m3tal dash restart` |
| `m3tal dash status` | Shows runtime container state. | `m3tal dash status` |
| `m3tal dash logs` | Streams Dashboard logs. | `m3tal dash logs -f` |

---

## 5. Infrastructure Stack Operations
Controls stacks defined in `/opt/m3tal/stack` (aliased to `/docker`).

| Command | Description | Example |
| :--- | :--- | :--- |
| `m3tal up` | Spins up the full infrastructure stack. | `m3tal up` |
| `m3tal down` | Tears down the active infrastructure stack. | `m3tal down` |
| `m3tal logs` | Streams aggregated logs from all services. | `m3tal logs` |

## Appendix: Environment Variable Reference
*Default system configuration state:*

| Variable | Default Value | Description |
| :--- | :--- | :--- |
| `DASHBOARD_PORT` | 8082 | Port exposed for the UI |
| `STATE_DIR` | ./state | Local database storage path |
| `API_TOKEN` | change_me_api_token | Backend communication token |
| `NETWORK_NAME` | m3tal | Docker overlay network |
| `DOMAIN` | localhost | Base service domain |
| `PUID` / `PGID` | 1000 | User permission mapping |

**Architecture Pathing:**
*   **Config:** `/etc/m3tal/.env`
*   **Database:** `/var/lib/m3tal/state.db`
*   **Stacks:** `/opt/m3tal/stack`
