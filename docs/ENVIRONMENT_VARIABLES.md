# M3TAL Environment Variables Reference

All M3TAL environment variables are read from `/etc/m3tal/.env` by both the CLI and all Docker Compose stacks via `--env-file`. This file is managed by the `m3tal config wizard` and individual `m3tal config set` commands.

## Quick Reference Table

| Variable Name         | Default Value      | Description                                                                                                                                                                                                                                  |
|-----------------------|--------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Core**              |                    |                                                                                                                                                                                                                                              |
| `DASHBOARD_PORT`      | `8082`             | The internal port the M3TAL Dashboard runs on.                                                                                                                                                                                               |
| `HTTP_PORT`           | `8080`             | The internal port the M3TAL API daemon runs on.                                                                                                                                                                                              |
| `STATE_DIR`           | `./state`          | The directory where M3TAL stores its SQLite database and other state files.                                                                                                                                                                  |
| `LOG_LEVEL`           | `info`             | Controls the verbosity of logs. Options include: `debug`, `info`, `warn`, `error`.                                                                                                                                                           |
| `DEBUG_MODE`          | `false`            | Enables or disables debug mode for enhanced logging and diagnostics.                                                                                                                                                                           |
| `METRICS_ENABLED`     | `true`             | Enables or disables the collection and exposition of system metrics.                                                                                                                                                                           |
| `PUID`                | `1000`             | The User ID for running Docker containers. This should match the user ID of the host system user that owns the M3TAL data directories.                                                                                                           |
| `PGID`                | `1000`             | The Group ID for running Docker containers. This should match the group ID of the host system user that owns the M3TAL data directories.                                                                                                         |
| `TZ`                  | `America/Denver`   | The timezone for M3TAL services. Ensure this is a valid IANA timezone name.                                                                                                                                                                  |
| **Authentication**    |                    |                                                                                                                                                                                                                                              |
| `DASHBOARD_SECRET`    | `change_me_immediately` | A secret key used for securing the M3TAL Dashboard. **Auto-generated on first `m3tal init`. DO NOT SET MANUALLY unless rotating.**                                                                                                           |
| `API_TOKEN`           | `change_me_api_token` | A token used for authenticating API requests. **Auto-generated on first `m3tal init`. DO NOT SET MANUALLY unless rotating.**                                                                                                               |
| `ADMIN_PASSWORD`      | `admin_pass`       | The password for the default `admin` user of the M3TAL Dashboard.                                                                                                                                                                            |
| **Network**           |                    |                                                                                                                                                                                                                                              |
| `LOCAL_IP`            | `127.0.0.1`        | The local IP address M3TAL services will bind to.                                                                                                                                                                                            |
| `NETWORK_NAME`        | `m3tal`            | The name of the Docker network M3TAL services will join.                                                                                                                                                                                     |
| **Storage**           |                    |                                                                                                                                                                                                                                              |
| `BASE_STORAGE_PATH`   | `./data`           | The base directory for all M3TAL data. **Defaults to `/mnt` in production deployments.**                                                                                                                                                     |
| `MEDIA_PATH`          | `./data/media`     | The directory where media data is stored.                                                                                                                                                                                                    |
| `CONFIG_PATH`         | `./data/config`    | The directory where configuration files are stored.                                                                                                                                                                                          |
| `DOWNLOADS_PATH`      | `./data/downloads` | The directory where downloads are stored.                                                                                                                                                                                                    |
| **Traefik**           |                    |                                                                                                                                                                                                                                              |
| `DOMAIN`              | `localhost`        | The primary domain for M3TAL services. Setting this enables `dash.DOMAIN` and `api.DOMAIN` routes via Traefik.                                                                                                                               |
| `TRAEFIK_WEB_PORT`    | `80`               | The host port that Traefik will expose for HTTP traffic.                                                                                                                                                                                     |
| `TRAEFIK_WEBHTTPS_PORT` | `443`              | The host port that Traefik will expose for HTTPS traffic.                                                                                                                                                                                    |
| `TRAEFIK_DASHBOARD_PORT` | `8080`             | The internal port the Traefik dashboard is accessible on. **Note:** This is the port Traefik itself runs on, NOT the port M3TAL uses to access Traefik. Access is typically `127.0.0.1:8081` on the host.                                     |
| **VPN**               |                    |                                                                                                                                                                                                                                              |
| `VPN_USER`            | `user`             | The username for VPN authentication.                                                                                                                                                                                                         |
| `VPN_PASSWORD`        | `password`         | The password for VPN authentication.                                                                                                                                                                                                         |

## Detailed Environment Variable Reference

All environment variables are read from `/etc/m3tal/.env` by both the CLI and all Docker Compose stacks via `--env-file`.

### Core

| Name                | Description                                                                                                                                                                                                                                 | Default Value    | Example Value        | Used By                                                                                                                                                               |
|---------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------|----------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `DASHBOARD_PORT`    | The internal port the M3TAL Dashboard container runs on. This is used for direct access in `local` mode and for Traefik routing in `traefik` mode.                                                                                             | `8082`           | `8082`               | `m3tal-dashboard` container                                                                                                                                           |
| `HTTP_PORT`         | The internal port the M3TAL API daemon (Go binary) runs on. This is the primary API endpoint for the dashboard and CLI.                                                                                                                     | `8080`           | `5050`               | `m3tal-api.service`, `m3tal-dashboard` container (via `GO_API_URL`)                                                                                                    |
| `STATE_DIR`         | The directory where M3TAL stores its SQLite database (`state.db`) and other runtime state files.                                                                                                                                            | `./state`        | `/var/lib/m3tal/state` | `m3tal-api.service`, `m3tal-dashboard` container                                                                                                                      |
| `LOG_LEVEL`         | Controls the verbosity of logs emitted by M3TAL services. Valid options include `debug`, `info`, `warn`, and `error`.                                                                                                                     | `info`           | `debug`              | `m3tal-api.service`, `m3tal-dashboard` container                                                                                                                      |
| `DEBUG_MODE`        | When set to `true`, enables debug logging and potentially other diagnostic features across M3TAL services.                                                                                                                                | `false`          | `true`               | `m3tal-api.service`, `m3tal-dashboard` container                                                                                                                      |
| `METRICS_ENABLED`   | When set to `true`, M3TAL services will expose Prometheus-compatible metrics.                                                                                                                                                               | `true`           | `false`              | `m3tal-api.service`                                                                                                                                                   |
| `PUID`              | The User ID for running Docker containers. This should typically match the `uid` of the host system user that owns the M3TAL data directories to ensure proper file permissions.                                                             | `1000`           | `1000`               | `m3tal-dashboard` container, `ollama` container (if applicable)                                                                                                       |
| `PGID`              | The Group ID for running Docker containers. This should typically match the `gid` of the host system user that owns the M3TAL data directories to ensure proper file permissions.                                                             | `1000`           | `1000`               | `m3tal-dashboard` container, `ollama` container (if applicable)                                                                                                       |
| `TZ`                | The timezone for M3TAL services. This ensures that timestamps in logs and other time-sensitive operations are accurate. Ensure this is a valid IANA timezone name (e.g., `America/New_York`, `Europe/London`).                              | `America/Denver` | `UTC`                | `m3tal-dashboard` container                                                                                                                                           |

### Authentication

| Name                 | Description                                                                                                                                                                                                                                 | Default Value           | Example Value             | Used By                                                                                                                                                               |
|----------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------|---------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `DASHBOARD_SECRET`   | A secret key used for securing sessions and communication within the M3TAL Dashboard. **This variable is auto-generated on the first `m3tal init` command and should generally NOT be set manually unless you are intentionally rotating it.** | `change_me_immediately` | `a_very_secret_key_123` | `m3tal-dashboard` container                                                                                                                                           |
| `API_TOKEN`          | A token used for authenticating API requests to the M3TAL API daemon. **This variable is auto-generated on the first `m3tal init` command and should generally NOT be set manually unless you are intentionally rotating it.**                   | `change_me_api_token`   | `another_api_token_xyz` | `m3tal-api.service` (internally), used by CLI and Dashboard for auth.                                                                                                 |
| `ADMIN_PASSWORD`     | The password for the default `admin` user of the M3TAL Dashboard. It's highly recommended to change this default value.                                                                                                                    | `admin_pass`            | `my_secure_password`      | `m3tal-dashboard` container (for initial login), `m3tal dashpass` command                                                                                             |

### Network

| Name          | Description                                                                                                                                                                                                                 | Default Value   | Example Value   | Used By                                  |
|---------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------|-----------------|------------------------------------------|
| `LOCAL_IP`    | The local IP address that M3TAL services will bind to. This is typically set to `127.0.0.1` for host-local services.                                                                                                          | `127.0.0.1`     | `192.168.1.100` | `m3tal-api.service`                      |
| `NETWORK_NAME`| The name of the Docker network that M3TAL services will join. This is used by Docker Compose to connect services together.                                                                                                   | `m3tal`         | `m3tal_net`     | Docker Compose (all services)            |

### Storage

| Name                 | Description                                                                                                                                                                                                                              | Default Value   | Example Value      | Used By                                                                                               |
|----------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------|--------------------|-------------------------------------------------------------------------------------------------------|
| `BASE_STORAGE_PATH`  | The base directory for all M3TAL data. **This defaults to `./data` in template configurations but defaults to `/mnt` in production deployments.** All other storage-related paths are subdirectories of this.                             | `./data`        | `/mnt`             | `m3tal-dashboard` container, Docker Compose (volumes)                                                   |
| `MEDIA_PATH`         | The directory where media files (e.g., uploaded images, videos) are stored. This is a subdirectory of `BASE_STORAGE_PATH`.                                                                                                                | `./data/media`  | `/mnt/media`       | `m3tal-dashboard` container (volume mapping)                                                          |
| `CONFIG_PATH`        | The directory where M3TAL stores its configuration files, including the dashboard's user credentials. This is a subdirectory of `BASE_STORAGE_PATH`.                                                                                        | `./data/config` | `/mnt/config`      | `m3tal-dashboard` container (volume mapping)                                                          |
| `DOWNLOADS_PATH`     | The directory where downloaded files or artifacts are stored. This is a subdirectory of `BASE_STORAGE_PATH`.                                                                                                                             | `./data/downloads`| `/mnt/downloads`   | `m3tal-dashboard` container (volume mapping)                                                          |

### Traefik

| Name                  | Description                                                                                                                                                                                                                                                                                               | Default Value   | Example Value   | Used By                                                                                                                                                                                                                                                                       |
|-----------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------|-----------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `DOMAIN`              | The primary domain name for accessing M3TAL services. When set, Traefik will be configured to route traffic to `api.DOMAIN` for the API daemon and `dash.DOMAIN` for the dashboard (when `DASHBOARD_EXPOSE_MODE=traefik`). **Setting this is crucial for domain-based access.**                               | `localhost`     | `m3tal.example.com` | Traefik configuration, `m3tal-dashboard` container (via labels in `m3tal-compose.traefik.yml`), Traefik configuration (dynamic/api.yml)                                                                                                                                         |
| `TRAEFIK_WEB_PORT`    | The host port that Traefik will expose for incoming HTTP traffic. This is typically port `80`.                                                                                                                                                                                                             | `80`            | `80`            | Traefik container (entrypoint configuration)                                                                                                                                                                                                                                  |
| `TRAEFIK_WEBHTTPS_PORT` | The host port that Traefik will expose for incoming HTTPS traffic. This is typically port `443`.                                                                                                                                                                                                          | `443`           | `443`           | Traefik container (entrypoint configuration)                                                                                                                                                                                                                                  |
| `TRAEFIK_DASHBOARD_PORT`| The internal port that the Traefik dashboard itself is accessible on within the Docker network. **Note:** This is NOT the port M3TAL uses to access Traefik services. The Traefik dashboard is typically exposed on `127.0.0.1:8081` on the host by default.                                             | `8080`          | `8080`          | Traefik container (internal service port)                                                                                                                                                                                                                                     |
