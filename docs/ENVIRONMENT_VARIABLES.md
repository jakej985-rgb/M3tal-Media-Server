# M3TAL Ecosystem: Environment Configuration Reference

This document serves as the master reference for the `M3TAL` orchestrator environment variables. These configurations control the behavior of the `m3tal` control plane, the Go-native API backend, and the associated containerized infrastructure stacks.

## ⚠️ Critical Note on Auto-Generation
Variables marked with **[AUTO-GEN]** are automatically generated by the `m3tal` orchestrator on the first system boot if not explicitly defined in `/etc/m3tal/.env`. It is highly recommended to rotate these tokens post-installation.

## Deployment Standards

### Path Hierarchy
All data-plane paths defined via `BASE_STORAGE_PATH` and derivatives (`MEDIA_PATH`, `CONFIG_PATH`) must be absolute paths when deploying in production mode to ensure `systemd` persistence and proper container volume mounting.

### Permission Mapping
The `PUID` and `PGID` variables are injected into all `deploy/stack` services to ensure that the Go orchestrator and the Docker containers share file ownership on the host filesystem, preventing "permission denied" errors during database writes or media processing.

### Security
- **[AUTO-GEN]** values are handled by the `m3tal init` process. If you are modifying these manually, perform a `m3tal restart` to ensure the Go backend reloads the environment tokens from the `/etc/m3tal/.env` file.
- The `ADMIN_PASSWORD` should be stored as a cryptographically strong hash if the instance is exposed to a public network.
