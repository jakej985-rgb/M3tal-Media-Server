# M3TAL Environment Variables Reference

All M3TAL configuration is managed through environment variables, primarily stored in `/etc/m3tal/.env`. This file is read by both the M3TAL CLI and all Docker Compose stacks via `--env-file`, ensuring a consistent configuration across the ecosystem.

The `m3tal config wizard` command is the recommended way to set and manage these variables.

## Core

### `LOG_LEVEL`

*   **Description:** Controls the verbosity of logs generated by M3TAL services.
*   **Default Value:** `info`
*   **Example Value:** `debug`
*   **Used By:** API daemon, Dashboard container

### `DEBUG_MODE`

*   **Description:** Enables debug mode for enhanced logging and troubleshooting. When set to `true`, more detailed information will be logged.
*   **Default Value:** `false`
*   **Example Value:** `true`
*   **Used By:** API daemon, Dashboard container

### `TZ`

*   **Description:** Sets the timezone for M3TAL services. This ensures that logs and timestamps are accurate for your region.
*   **Default Value:** `America/Denver`
*   **Example Value:** `Europe/London`
*   **Used By:** API daemon, Dashboard container

### `PUID`

*   **Description:** The User ID (UID) that Docker containers will run as. This is important for file permissions.
*   **Default Value:** `1000`
*   **Example Value:** `1001`
*   **Used By:** API daemon, Dashboard container

### `PGID`

*   **Description:** The Group ID (GID) that Docker containers will run as. This is important for file permissions.
*   **Default Value:** `1000`
*   **Example Value:** `1001`
*   **Used By:** API daemon, Dashboard container

### `STATE_DIR`

*   **Description:** Specifies the directory where M3TAL's state database (`state.db`) and other internal configuration files are stored.
*   **Default Value:** `./state`
*   **Example Value:** `/var/lib/m3tal/state`
*   **Used By:** API daemon, Dashboard container

### `METRICS_ENABLED`

*   **Description:** Enables Prometheus metrics collection for M3TAL services.
*   **Default Value:** `true`
*   **Example Value:** `false`
*   **Used By:** API daemon

## Auth

### `DASHBOARD_SECRET`

*   **Description:** A secret key used for securing the M3TAL Dashboard. **This variable is auto-generated on the first `m3tal init` command.** Users should generally NOT set this manually unless rotating the secret.
*   **Default Value:** `change_me_immediately`
*   **Example Value:** `a_very_secret_and_random_string`
*   **Used By:** Dashboard container

### `API_TOKEN`

*   **Description:** A token used for authenticating API requests. **This variable is auto-generated on the first `m3tal init` command.** Users should generally NOT set this manually unless rotating the token.
*   **Default Value:** `change_me_api_token`
*   **Example Value:** `another_secure_api_token`
*   **Used By:** API daemon

### `ADMIN_PASSWORD`

*   **Description:** The password for accessing the M3TAL Dashboard's administrative functions.
*   **Default Value:** `admin_pass`
*   **Example Value:** `my_secure_admin_password`
*   **Used By:** Dashboard container

## Network

### `HTTP_PORT`

*   **Description:** The port on which the M3TAL API daemon (Go binary) listens for incoming HTTP requests.
*   **Default Value:** `8080`
*   **Example Value:** `9090`
*   **Used By:** API daemon

### `NETWORK_NAME`

*   **Description:** The name of the Docker network that M3TAL services will be connected to. This is typically the network used for inter-container communication and Traefik.
*   **Default Value:** `m3tal`
*   **Example Value:** `m3tal_net`
*   **Used By:** API daemon, Dashboard container, Traefik container

### `LOCAL_IP`

*   **Description:** The IP address that M3TAL services will bind to for local communication. This is often `127.0.0.1` or `host.docker.internal` depending on the context.
*   **Default Value:** `127.0.0.1`
*   **Example Value:** `host.docker.internal`
*   **Used By:** API daemon

### `DOMAIN`

*   **Description:** The primary domain name for your M3TAL deployment. Setting this variable enables Traefik to route traffic to services using subdomains like `dash.DOMAIN` and `api.DOMAIN`.
*   **Default Value:** `localhost`
*   **Example Value:** `m3tal.example.com`
*   **Used By:** API daemon, Dashboard container (for Traefik routing), Traefik container

### `VPN_USER`

*   **Description:** The username for establishing a VPN connection, if one is configured for M3TAL.
*   **Default Value:** `user`
*   **Example Value:** `vpnuser123`
*   **Used By:** API daemon

### `VPN_PASSWORD`

*   **Description:** The password for establishing a VPN connection, if one is configured for M3TAL.
*   **Default Value:** `password`
*   **Example Value:** `a_strong_vpn_password`
*   **Used By:** API daemon

## Storage

### `BASE_STORAGE_PATH`

*   **Description:** The base directory for all M3TAL data storage. This includes configuration, media, and downloads. **In production deployments, this defaults to `/mnt`. In template/development environments, it may default to `./data`.**
*   **Default Value:** `./data`
*   **Example Value:** `/mnt/m3tal_storage`
*   **Used By:** API daemon, Dashboard container

### `MEDIA_PATH`

*   **Description:** The specific path within `BASE_STORAGE_PATH` where media files are stored.
*   **Default Value:** `./data/media`
*   **Example Value:** `/mnt/m3tal_storage/media`
*   **Used By:** API daemon, Dashboard container

### `CONFIG_PATH`

*   **Description:** The specific path within `BASE_STORAGE_PATH` where M3TAL's configuration files are stored.
*   **Default Value:** `./data/config`
*   **Example Value:** `/mnt/m3tal_storage/config`
*   **Used By:** API daemon, Dashboard container

### `DOWNLOADS_PATH`

*   **Description:** The specific path within `BASE_STORAGE_PATH` where downloaded files are stored.
*   **Default Value:** `./data/downloads`
*   **Example Value:** `/mnt/m3tal_storage/downloads`
*   **Used By:** API daemon, Dashboard container

## Dashboard

### `DASHBOARD_PORT`

*   **Description:** The port on which the M3TAL Dashboard container listens for incoming connections.
*   **Default Value:** `8082`
*   **Example Value:** `8083`
*   **Used By:** Dashboard container

### `DASHBOARD_EXPOSE_MODE`

*   **Description:** Controls how the M3TAL Dashboard is exposed to the network.
    *   `local`: The dashboard is exposed directly via a port binding on the host (`DASHBOARD_PORT`). Access via `http://HOST_IP:DASHBOARD_PORT`. No Traefik is required for this mode.
    *   `traefik`: The dashboard is exposed through Traefik. Access via `http://dash.DOMAIN`. Traefik must be running and configured for this mode.
*   **Default Value:** `local`
*   **Example Value:** `traefik`
*   **Used By:** Dashboard container (influences compose overrides)

## Traefik

### `TRAEFIK_WEB_PORT`

*   **Description:** The port on the host machine that Traefik uses as its entry point for HTTP traffic.
*   **Default Value:** `80`
*   **Example Value:** `8000`
*   **Used By:** Traefik container

### `TRAEFIK_WEBHTTPS_PORT`

*   **Description:** The port on the host machine that Traefik uses as its entry point for HTTPS traffic.
*   **Default Value:** `443`
*   **Example Value:** `8443`
*   **Used By:** Traefik container

### `TRAEFIK_DASHBOARD_PORT`

*   **Description:** The internal port on which Traefik listens for its own dashboard interface. This is typically exposed via `127.0.0.1:8081` on the host.
*   **Default Value:** `8080`
*   **Example Value:** `8081`
*   **Used By:** Traefik container
